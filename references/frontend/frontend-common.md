# 前端通用规范

- 识别框架、构建工具、路由、状态管理、请求层、组件库、样式、lint 和测试版本；遵循既有架构。
- 组件职责清晰，避免巨型页面和重复业务逻辑。
- 状态放在满足共享范围的最小位置；区分服务端状态、URL 状态和本地 UI 状态。
- 不复制可推导状态；统一处理加载、成功、空数据、错误、取消和重复提交。
- 表单校验与服务端规则保持一致；前端校验不能替代服务端校验。
- 不在前端存储服务端密钥；避免不可信 HTML 注入。
- 隐藏权限按钮不能替代服务端鉴权。
- 关注键盘可访问性、焦点、语义标签、响应式布局和加载反馈。
- 遵循项目 ESLint、Prettier、TypeScript、单元和 E2E 工具；验证错误路径与关键交互。
