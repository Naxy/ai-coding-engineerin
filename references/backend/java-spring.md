# Java / Spring Boot 专项规范

- 识别 JDK、Spring Boot、ORM、构建工具和测试框架版本，不默认使用最新版 API。
- 遵循现有分层；Controller 负责协议适配，Service 组织用例和事务，Repository/Mapper 聚焦持久化。
- 优先构造器注入；避免字段注入和静态 Service Locator。
- DTO、领域对象、持久化对象按实际复杂度区分，避免无意义映射层。
- 异常映射集中且语义明确；不吞异常或返回伪成功。
- 金额使用 BigDecimal，明确精度、舍入和币种；时间明确时区。
- 明确事务边界、传播、隔离和回滚条件；注意 Spring 代理、自调用导致事务注解不生效。
- 不在长事务中执行慢速远程调用；结合业务设计幂等、锁、唯一约束和重试。
- 关注分页、批量写入和索引；运行项目已有 Maven/Gradle、单元及集成测试并报告真实结果。
