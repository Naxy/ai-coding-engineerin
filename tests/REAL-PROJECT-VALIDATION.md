## 验证任务与结果

### 1. Excel 金额格式校验 Bug 修复

- 模式：Quick。问题局限于金额解析，且能用针对性测试覆盖。
- 发现：解析器直接删除所有逗号，导致分组格式错误的金额也可能被接受。
- 处理：校验数字与千位分组格式；保留合法千位分隔符、科学计数法及既有人民币符号输入。
- 测试：覆盖合法千位分组、科学计数法和非法分组，并检查错误包含 Excel 行号。
- 结果：通过。

### 2. 异常处理 API 与核对结果关联校验

- 模式：Standard。该修改影响常规业务接口写入的数据完整性。
- 发现：处理任务写入接口没有确认异常编码及订单编号属于指定核对运行。
- 处理：写入前读取该次核对快照，校验订单级异常或全局异常确实存在；无可用明细或异常不匹配时拒绝写入。
- 测试：覆盖正确订单级异常、正确全局异常、错误订单归属及不存在的异常编码。
- 结果：通过。

### 3. 金额核验与核对结果事务一致性

- 模式：High-Risk。任务涉及金额判断及持久化一致性。
- 发现：核对运行记录与序列化结果快照分两次写入；若第二次写入失败，可能留下无完整结果的运行记录。
- 处理：将核对执行方法置于 Spring 事务中，使运行记录及快照写入处于同一事务边界。
- 测试：覆盖 `0.10 + 0.20 = 0.30` 的 BigDecimal 累计、正常匹配，以及部分发货和金额差异异常。
- 结果：业务逻辑单元测试通过。未连接真实数据库验证事务回滚。
